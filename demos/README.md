# Demos

Per-demo folders live here, one per `<id>/`. Each folder is the
single-source-of-truth spec for a tight, repeatable on-stage or
pre-recorded demo derived from one of the workshops in
[`../workshops/`](../workshops/).

- Author a demo with the [`add-demo`](../.agents/skills/add-demo/SKILL.md) skill.
- Drive it beat-by-beat with [`run-demo`](../.agents/skills/run-demo/SKILL.md).
- Design doc: [`../.plans/demo-skills-plan.md`](../.plans/demo-skills-plan.md).

See [`SESSIONS.md`](./SESSIONS.md) for the registry of named Copilot
sessions per demo (filled in by `run-demo/start`).
