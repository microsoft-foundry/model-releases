# Hugging Face

> **Open-source model catalog on Microsoft Foundry.** A large, curated
> selection of Hugging Face community models deployable directly into
> your Foundry project.

## Why it matters

When you need a specific open-source model — a small language model, a
specialized embedding model, a niche vision model — Hugging Face is
usually where it lives. Microsoft Foundry gives you a managed path to
deploy and scale them.
