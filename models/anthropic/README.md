# Anthropic

> **The Claude family on Microsoft Foundry.** Long-context, tool-using
> assistants known for careful, well-formatted responses.

## Why it matters

Claude models are a strong option when you need long-context reasoning,
structured tool use, and safety-tuned behavior alongside — or as a
complement to — the Azure OpenAI family.
