# Azure OpenAI Models on Microsoft Foundry

> **GPT-family models hosted on Microsoft Foundry.** The workhorse family
> for chat, reasoning, vision, function calling, and fine-tuning across
> production Azure workloads.

## Why it matters

Azure OpenAI is where most Microsoft Foundry projects start: broad
capability coverage, enterprise controls, and a shared SDK surface with
the wider OpenAI ecosystem. New GPT-family releases land here first and
drive the patterns other families follow.
