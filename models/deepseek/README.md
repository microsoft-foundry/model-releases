# DeepSeek

> **DeepSeek reasoning and chat models on Microsoft Foundry.** Known for
> strong open-weight reasoning models like DeepSeek-R1.

## Why it matters

DeepSeek's reasoning models expose explicit reasoning traces, which is
useful for debugging, distillation, and any workflow where seeing the
model's "work" matters. They're often the first stop when you want a
reasoning-class model outside the OpenAI / Anthropic families.
